# Graph RAG brand kit

Every file here is generated by [`tools/build_brand.py`](tools/build_brand.py). Edit the script and regenerate; don't hand-edit the outputs.

```powershell
cargo install resvg --locked --version 0.48.1   # once, for PNG exports
uv run docs/brand/tools/build_brand.py
```

The script downloads two OFL-licensed font releases into `tools/.cache/` (git-ignored), checks their SHA-256, outlines all text to SVG paths, rejects any SVG containing scripts, event handlers, `href`, or `url()` references, checks palette contrast, renders the PNGs with resvg, and verifies each PNG was actually rewritten.

## The mark

A retrieved node (mint, with a similarity halo) and its graph neighbourhood. Vector search finds the hit; the graph supplies what it's connected to. That's the product in one picture.

`src/graph_rag/brand.py` is also generated: the API serves its `FAVICON_SVG` at `/favicon.svg` and uses `THEME_COLOR` on the built-in page.

## Palette

Taken from the built-in query page in `src/graph_rag/api.py`, plus one accent for dark surfaces.

| Token | Hex | Role |
|---|---|---|
| Ink | `#17221F` | tile, text on light |
| Ink deep | `#111A17` | banner / social background |
| Paper | `#EEF2F0` | nodes and text on dark |
| Green | `#17624F` | accent on light (7.25:1 on white) |
| Mint | `#5CD6A6` | accent on dark (10.48:1 on GitHub dark) |
| Muted | `#9DB1AA` | secondary text on dark (7.86:1) |

## Type

- **Source Serif 4 Display Bold** (Adobe, SIL OFL 1.1): "Graph", diagram titles. Echoes the serif headline of the built-in page.
- **Inter** Medium / SemiBold / Bold (Rasmus Andersson, SIL OFL 1.1): "RAG", taglines, labels.

The OFL permits using glyph outlines in artwork such as logos. The fonts themselves aren't redistributed.
